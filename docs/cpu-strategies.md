# CPU 戦略仕様

このドキュメントでは、ナショナルエコノミー vs CPU で実装している4種類のCPU戦略のルールと優先順位を説明する。

---

## 1. ランダム（random）

### コンセプト
すべての判断を乱数で行う最も素朴な戦略。テスト・比較のベースラインとして機能する。入門者向けの対戦相手として適している。

### 職場選択ルール
- 配置可能な一般職場と所有建物の中から、50%の確率で一般職場側・50%で所有建物側を選ぶ
- 選ばれた側の中からランダムに1箇所を選択する

### カード選択ルール
- 公開ピック選択：ランダムに1枚ピック
- 建設：建設可能なカードの中からランダムに選ぶ
- 捨て札：手札の先頭から順に捨てる（カードの種類や価値を考慮しない）

### 想定される強さ
弱い。選択の一貫性がなく、賃金を払えずに建物を売ることが多い。

---

## 2. 貪欲法（greedy）

### コンセプト
ゲームのルールから導いた価値関数で各アクションをスコアリングし、最高スコアの職場・建物を選ぶ。先読みはせず、現在のターンで最も良いと思われる手を貪欲に選ぶ。「賢いが短期的」な思考パターン。

### 職場選択ルール（スコアリング）

各効果の基本スコア（高いほど優先）：

| 効果 | スコア | 条件・注釈 |
|---|---|---|
| 同コスト2棟建設（build-double） | 110 | 建設可能ペアがなければ選択不可 |
| 建設（build） | 85 + 建設可能最高コスト×3 | 賃金が払えない状況では×0.3に減少 / 建設不可なら選択不可 |
| 農場無料建設（build-farm-free） | 70 | 農場カードが手札になければ選択不可 |
| 大学（労働者を5人に増員） | 100×減衰係数 | 労働者が既に5人以上、またはラウンド7以降なら選択不可 |
| 高等学校（労働者を4人に増員） | 80×減衰係数 | 労働者が既に4人以上、またはラウンド7以降なら選択不可 |
| 学校（労働者を1人雇用・研修中） | 90×減衰係数（労働者2人時）/ 50×減衰係数（それ以上） | ラウンド7以降は選択不可 |
| 専門学校（労働者を即時1人雇用） | 70 | 上限到達で選択不可 |
| 公開ピック（reveal-pick） | 55（手札3枚未満は70） | 手札が少ないときに優先度アップ |
| 捨てドロー系（discard-draw） | draw数×10 | 手札が捨て枚数未満なら選択不可 |
| お金獲得（discard-gain） | 獲得額×2.5（残金不足時は×1.8倍） | お金が賃金の1.5倍を下回ると優先度アップ |
| ドロー（draw） | n×12 | |
| 空手ドロー（draw-if-empty） | 手札0枚時はempty×12、それ以外はnormal×12 | |
| 採石場（draw-become-start） | 30 | |
| 焼畑（slash-burn） | 25 | |
| サプライからお金（gain-supply） | n×3 | |
| 消費財ドロー | n×4 | |
| 消費財補充（draw-consumption-to） | (目標 - 現在枚数)×4 | 手札が目標以上なら選択不可 |

**減衰係数**：労働者増員系のスコアはラウンドが進むにつれ減衰する。係数 = `1 - (round - 1) / 9`。ラウンド7以降は研修・増員系施設を選ばない（即時雇用の専門学校は例外で減衰なし）。

**賃金支払い能力の考慮**：build効果のスコアは、現在の手持ちが賃金（労働者数×賃金額）を下回っている場合に大幅に下がる。これにより「建設した建物をすぐ売ることになる」ロスを回避する。なお、賃金は労働者数と賃金額のみで決まり、建物は影響しない。

### カード選択ルール
- **建設**：ラウンド1〜7は建設可能なカードのうちコストが最大のものを選ぶ（効果を長期間活用できる）。ラウンド8〜9は残りラウンドが少ないためassetValueが最大のものを選ぶ（得点効率重視）。賃金を払えない状況では建設をキャンセルする
- **農場無料建設**：農場系カードのうちassetValueが最大のものを選ぶ
- **同コスト2棟建設**：コストが最大のペアを選ぶ
- **捨て札**：消費財→assetValueが低い建物の順に捨てる（有用なカードを手元に残す）
- **公開ピック**：assetValueが最大のカードを選ぶ

### 想定される強さ
中程度。序盤から建物を積極的に建設して得点を稼ぎ、学校系で労働者を増やす。お金管理を意識するため賃金未払いは少ない。ただし相手の状況を考慮しないため、後半は読まれやすい。

## 3. モンテカルロ（mcts）

### コンセプト
各選択肢について複数のゲームシミュレーションを実行し、期待スコアが最も高い手を選ぶ。短期的な評価ではなくゲーム終了時の最終スコアで判断するため、長期的に有利な手を選びやすい。

### シミュレーション方法
- 選択肢ごとに `MCTS_SIMULATIONS`（現在10）回のシミュレーションを実行する
- 各シミュレーションでは、全プレイヤーの戦略を変換してゲーム終了まで自動進行させる
  - MCTSプレイヤー → 貪欲法（greedy）に変換（再帰的MCTS展開を防ぐため）
  - 人間プレイヤー → 貪欲法（greedy）に変換（人間の手番が詰まらないようにするため）
  - その他のCPU（greedy、disruptive、random）は元の戦略を維持
- シミュレーションごとに異なる乱数シードを使用し、結果の多様性を確保する
- シミュレーション後の自分のプレイヤーの最終スコア（建物得点＋残金＋ボーナス－ペナルティ）を平均し、最も高い選択肢を実際の手として採用する
- シミュレーションはゲームの複製状態で行われるため、実際のゲーム進行には影響しない

### 職場選択ルール
- 上記シミュレーション結果に基づいて、期待最終スコアが最大の職場・建物を選ぶ

### カード選択ルール
モンテカルロは職場・建物の選択判断のみ担当する。カードの具体的な選択（どれを建設するか、どれを捨てるか）は貪欲法と同じ動作をする。

### 性能について
- N=10・選択肢6つの場合、ゲーム60回分を事前シミュレーションする
- 各シミュレーションはJavaScriptオブジェクトのコピーのみで構成されるため、処理は高速
- 体感的なUI遅延は30ms以内を想定

### 想定される強さ
強い。特に序盤（残りラウンドが多い）ほど長期的視野で有利な手を選ぶ。シミュレーション内では対戦相手も貪欲法で動作するため、相手の行動がより現実に近く評価精度が高い。

## 4. お邪魔（disruptive）

### コンセプト
相手が賃金支払いで売却した高コスト建物を一般職場として積極的に活用し、相手の資産損失を自分の利益に変える。自分自身は建物を売らないようお金を確保することを重視する。攻撃的な中級者向け戦略。

### 職場選択ルール（優先順位）

**優先度1：売られた建物（上位2コストグループ）**
- 一般職場の中から「売却によって一般職場化された建物」を特定する
- それらをコスト順に並べ、上位2コストグループに属する建物のみを対象とする
  - 例：コスト1・2・3・4の建物が一般職場にある場合、コスト3とコスト4が上位2グループ
- 対象の中でassetValueが最大の施設を選ぶ
- これにより、相手が高コスト建物を失うほど自分が有利になる構造を作る

**優先度2：今ラウンドの新施設**
- 売られた建物（上位2グループ）が利用できない場合、今ラウンドで新たに追加された一般職場を優先する
  - ラウンド2：露店 / ラウンド3：市場 / ラウンド4：高等学校 / ラウンド5：スーパーマーケット
  - ラウンド6：大学 / ラウンド7：百貨店 / ラウンド8：専門学校 / ラウンド9：万博
- 複数ある場合は、discard-gainの獲得額が最大のものを選ぶ（お金優先）

**優先度3：フォールバック**
- 上記いずれも利用できない場合は、利用可能な職場・所有建物の中から先頭のものを選ぶ

**所有建物について**：邪魔戦略は一般職場の活用を重視するため、所有建物への配置はフォールバック時のみ。

### カード選択ルール
- **建設**：コストが最小のカードを建設する（資金を温存し、自分の建物売却リスクを下げる）
- **同コスト2棟建設**：コストが最小のペアを選ぶ
- **捨て札**：消費財→assetValueが低い建物の順に捨てる（greedy同様）
- **その他**：ランダム戦略と同じ

### 想定される強さ
序盤は弱いが、相手（特にプレイヤー）が建物を売却し始める中盤以降に強みを発揮する。相手の失敗から利益を得るリアクション型の戦略。お金の確保を重視するため賃金未払いは少ない。
